# 🎓 CGPA Calculator

A modern and responsive CGPA Calculator built using HTML, CSS, and JavaScript.

## 🚀 Features

- Supports up to 8 semesters
- Dynamic SGPA input generation
- Instant CGPA calculation
- Input validation
- Responsive modern UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 📌 How It Works

1. Select the number of semesters
2. Enter SGPA values
3. Click on "Calculate CGPA"
4. View the final CGPA instantly
